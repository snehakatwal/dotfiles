# dotfiles

My Arch Linux + Hyprland setup.

## Install

```sh
git clone https://github.com/snehakatwal/dotfiles.git ~/projects/dotfiles
cd ~/projects/dotfiles
./install.sh    # packages + configs + SDDM theme
```

Only want the configs? `./apply.sh` copies them into `~` (your old ones go to `~/.dotfiles-backup/`).
